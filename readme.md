# ゴルフポイント Web版

## 使い方
1. `index.html` を公開すれば、そのままスマホのSafari/Chromeで使えます。
2. 設定画面で4人の名前、ホール賞ポイント、各ホールハンデ、ドラコン/ニアピン対象ホールを設定します。
3. スコア入力画面で各ホールのスコア、オリンピック、ドラコン、ニアピン、ホール賞を入力します。
4. 結果画面で3H/6H/9H/18Hを確認します。
5. 入力内容はブラウザの localStorage に保存されます。

## 重要
- ヨコ本体：各ホールのネット最少が単独勝者。引き分けは次ホールへ持越し。18H最終ホールが引き分けなら未解決持越しは消滅。
- オリンピック：ダイヤ5 / 金4 / 銀3 / 銅2 / 鉄1 / クズ鉄は表示上-3pt。集計は該当者以外の3人に各+1pt。
- クズ鉄：本人0、他3人に各+1。
- グランドスラム：ダイヤ〜鉄を5種類すべて獲得した人に+100。
- ドラコン/ニアピン：対象ホールで1pt。該当なしは次の対象ホールへ持越し。
- 3H/6Hなど途中はヨコのみ。
- 9H/18Hでネットスコアを表示。
- タテは設定した各ホールのハンデを使ったネットスコアとして、前半9H・後半9H・18Hのみ表示します。
- タテはヨコ（総合ポイント）には加算しません。

## 公開方法
- GitHub Pages
- Netlify
- Vercel

いずれもこのフォルダの3ファイルをそのまま公開できます。

- バードポイントのデフォルト：ホールインワン100 / アルバトロス100 / イーグル10 / バーディー1（4人共通の初期値）。
